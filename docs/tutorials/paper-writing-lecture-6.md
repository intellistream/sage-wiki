# 第6讲：培养写作能力

写作能力来自稳定练习和可执行反馈，不必等到实验全部完成才开始记录论证。本页整理课程中的写作训练方法。

## 先诊断障碍

- 空白恐惧：从最熟悉的方法、图表解释或一句贡献开始，不要求第一段就是最终引言。
- 结构混乱：先给每节写一句任务说明，再填材料；不相关内容暂放笔记。
- 拖延：将“写论文”改成一个可完成动作，如解释一张图的观察与原因。
- 完美主义：草稿先完成论证骨架，语言、格式分轮处理。

## 选择写作顺序

线性推进适合结构已清楚的稿件；模块起步适合已有实验和方法记录的稿件；结构驱动则先列问题—机制—证据，再写摘要和引言。三种方法可以混用，关键是各章节最终回答同一主问题。

## 建立反馈循环

1. 安排一个不被打断的短写作时段，开始前写下本次唯一目标。
2. 用版本记录保存变化；事实、实验配置和引用同步记录来源。
3. 隔天回读，尝试大声读出论证，标记跳跃、重复与未定义词。
4. 请同伴针对具体问题反馈，例如“是否理解机制为何有效”，而非只问“写得好吗”。
5. 将反馈分为内容、结构、语言三类，先修内容，再检查表达。

文献管理、协作编辑和语言工具可降低机械成本，但不能代替核验引用、实验或作者判断。不要把未公开论文与敏感数据上传到未经批准的外部工具。

练习成果：一段修订前后对照、三条修改理由和下一轮待验证的问题。延伸：[第8讲：毕业论文诊断](paper-writing-lecture-8.md)。
