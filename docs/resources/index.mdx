# 资源汇总

推荐书单、工具清单和常用链接。

从 [公开研究与教学资料索引](public-knowledge-index.md) 可进入已经公开的论文、课程、系统介绍和 Wiki 教程；[大模型推理系统论文阅读路径](inference-systems-reading-path.md)提供按问题递进的论文阅读框架。更新频繁的信息仍以原站为准。

## 如何添加

在此目录下创建新的 `.md` 或 `.mdx` 文件，汇总各类资源。

### 建议格式

```markdown
---
title: 资源类型
date: 2026-06-11
---

## 推荐书籍
- 《书名》 — 简介

## 推荐工具
- 工具名 — 用途说明

## 常用链接
- [链接名](https://...) — 说明
```
