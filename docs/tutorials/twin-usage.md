# Twin 学术分身的使用边界

Twin 是辅助准备和知识检索的学术分身，不是老师本人。适合用来整理研究问题、阅读材料、论文修改问题、实验计划和讨论提纲。检索结果与生成回答仍需核对；接口可用不等于答案正确。

## 如何提问

说明目标、已有材料、当前判断与卡点。例如：“请根据可访问的论文写作课程材料，检查这段引言是否交代了问题、机制和证据；指出依据不足的地方，不补造实验结果。”

课程问题可注明课程和讲次。研究问题应区分已观测结果和待验证假设。论文讨论前准备摘要、具体问题、希望重点检查的章节和时间要求；不要把未授权的私密材料发入公开会话。

## 如何核验回答

打开回答引用，确认来源确实支持对应主张，并检查日期、版本和适用条件。找不到依据时应要求明确说明缺失，而不是补出人名、指标或承诺。同一会话的历史可帮助理解问题，但不能替代事实来源与访问授权。

## 不能代办的决定

Twin 不能代表本人作出录取、评分、推荐信、经费、行政审批或时间安排等最终决定。讨论和预约准备不等于约定已获确认。涉及个人信息、未公开研究或承诺性事项，需由有权限的人通过正式流程确认。

遇到回答错误，反馈问题、引用与可公开的反例；不要附密钥或他人的私人会话。公开知识优先在 Wiki 修订，再同步到知识库，避免维护两份不同答案。
