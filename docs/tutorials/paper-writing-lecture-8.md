# 第8讲：毕业论文问题诊断与修订

把内容、结构、格式同时修改，容易掩盖真正的问题。课程建议按三层诊断：研究内容是否成立，论文框架是否清楚，最后检查格式规范。时间不足不能成为跳过内容验证的理由。

## 第一层：内容

检查问题定义不清、贡献边界模糊、动机不足、内容堆砌和实验与结论脱节。逐项回答：解决什么问题？为什么值得？与已有方法有什么实质差异？哪些实验支持这些差异？

建立“贡献—证据”对应表；找出最容易被推翻的结论，并说明需要什么对照。若删除某个实验后仍能作出完全相同的强结论，应检查该实验是否真的承担了验证任务。

## 第二层：结构

| 章节 | 应承担的任务 |
| --- | --- |
| 引言 | 定义问题，说明挑战，列出可验证的贡献。 |
| 相关工作 | 在一致的比较维度下说明差异，而不是罗列文章。 |
| 方法 | 解释设计原则、关键机制及其适用条件。 |
| 实验 | 验证贡献，解释观察，披露失败情形。 |
| 结论 | 回到主问题，交代已验证范围与局限。 |

每章都应能回答“它在主问题上推进了哪一步”。无法回答的章节需要重组，不能只靠过渡句连接。

## 第三层：格式与答辩

检查术语、图表、引用、符号、章节编号和学校的当前模板要求。修订计划依次安排内容补证、结构重排、格式统一和口头演练，不把某个固定倒计时当作通用规则。

答辩准备三组回答：核心创新用贡献、基线差异和证据说明；实验合理性用目标、场景约束和设置对应关系说明；局限用适用边界、已验证范围和后续工作说明。

练习成果：三层问题清单，每项注明证据位置、修复动作和验收方式。继续阅读：[系统论文修改清单](../standards/paper-revision-checklist.md)。
