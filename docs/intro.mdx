# Sage Wiki

欢迎来到 **Sage Wiki** —— IntelliStream 团队知识库。

这里存放团队的**技术成果、学习心得、教程指南**和**规范文档**，通过 Git 协作维护，人人皆可贡献。

## 如何贡献

仓库由 [intellistream/sage-wiki](https://github.com/intellistream/sage-wiki) 维护。新增内容请先阅读[贡献规范](standards/wiki-contribution.md)，补齐适用条件、步骤、验收与公开来源。内部讨论、凭据和未公开实验不能直接迁入。

1. Clone 本仓库
2. 在对应分类目录下创建 Markdown 文件
3. 提交 Pull Request 或直接 push 到 main 分支
4. 站点自动构建部署

:::tip 提示
左侧边栏可以快速导航到各个分类下的文章。
:::
