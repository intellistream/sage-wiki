# 第7讲：从选题到高质量论文

高质量论文需要选题、思考、实验与表达共同成立。追逐热点、堆积工作量或被动完成任务，都不能自动产生清楚的研究贡献。

## 选题的五项检查

1. 能否一句话说明输入、输出、约束和待解决的问题？
2. 是否理解最接近工作的机制及其边界，而不仅是论文标题？
3. 自己能否提出并检验一个机制假设？
4. 数据、算力、实现难度和时间是否允许完成最小验证？
5. 该问题是否与长期学习目标有关，是否值得持续投入？

首先回答三问：问题是什么，为什么重要，为什么尚未解决。再用[研究问题七步提问法](../standards/research-problem-framework.md)补齐实现与评测计划。

## 从阅读到判断

先读摘要、引言、图表和结论，建立问题地图；再读方法与实验细节，检查假设和证据；最后沿引用链寻找前驱、后续及同期方法。记录“作者声称什么”“实验实际证明什么”“我还不能判断什么”。阅读顺序可调整，但不能用快速浏览代替证据审查。

## 推进节奏

将课题拆为每周可验证的小目标，为深度工作安排稳定时间，减少频繁切换。每周回顾一次：新证据是否支持原假设，是否需要缩小范围或修改问题。科研反馈通常缓慢且非线性，应记录失败条件与判断变化，而不只记录成功结果。

拒稿意见是待分析的反馈，不是必须逐条接受的结论。区分误解、表达不足、证据缺口和研究本身的限制，分别处理。

练习成果：一页选题说明、一张相关工作比较表，以及一个可证伪的最小实验计划。
