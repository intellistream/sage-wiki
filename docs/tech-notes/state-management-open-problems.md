## 目的

本文梳理了大模型推理状态管理（尤其是 KV Cache 生命周期治理）领域的开放研究问题。每个问题映射到相关技术方向，给出待验证假设和所需实验基础设施。

适用于：推理系统方向的课题探索、KV Cache 优化研究、论文选题。

---

## 1. KV Cache 生命周期治理缺口

**核心判断：** 没有任何单一系统能在同一 TTFT/TPOT/SLO 边界下治理 KV 生命周期的全部五个阶段（admit, place, mutate, transfer, reclaim）。当前系统优化一到两个阶段而将债务外化到其他阶段。

### 实验问题

- **Q1.1:** 混合 prompt 长度负载下，不考虑下游传输代价的准入控制器 vs 联合推理准入+放置的控制器，p99 TPOT 差距多大？
- **Q1.2:** Prefill/Decode 分离创造了多少隐藏的"传输债务"？测量 KV 传输延迟占端到端 TTFT 的比例。
- **Q1.3:** 在什么占用率阈值下，反应式驱逐（PagedAttention 风格）开始比预期式准入限流更伤尾延迟？

---

## 2. 突发到达下的多租户服务

**核心判断：** 突发鲁棒性依赖于对短生命周期服务状态的连贯治理，而非任何单一优化旋钮。文献仍缺乏能对准入、卸载、恢复和租户隔离行动按同一服务边界排序的控制契约。

### 实验问题

- **Q2.1:** 突发性多租户流量下（混合 LoRA adapter），adapter 驻留搅动对吞吐的退化有多大？与热度感知驱逐策略对比。
- **Q2.2:** 优先级感知准入（提前拒绝低优先级请求）在突发下是否比尽力而为批处理有更好的 SLO 达成率？
- **Q2.3:** 两个租户共享 KV 内存池 vs 隔离时，p99 延迟膨胀有多大干扰成本？

---

## 3. Prefill/Decode 阶段分离代价

**核心判断：** 阶段分离（DistServe、Splitwise 风格）将瓶颈从计算不对称转移到了传输和恢复。剩余缺口是不确定性组合：实际运行时仍缺乏便携式规则来调和关于负载、内存和放置的错误或冲突预测。

### 实验问题

- **Q3.1:** 分离开销（KV 序列化 + 网络传输）超过阶段特化收益的交叉点在哪里？参数化：序列长度 × batch size × 网络带宽。
- **Q3.2:** 当 prefill 长度预测错误（±30%）时，goodput 相比反应式基线退化多少？
- **Q3.3:** 阶段不平衡突发（先 prefill 密集后 decode 密集）下，预期式阶段平衡 vs 反应式负载削减哪个恢复更快？

---

## 4. 扰动导向评测协议

**核心判断：** 对非平稳机制的一次性 benchmark 是反复出现的反模式。评测应覆盖 warmup → burst → reconfiguration → drift → long-horizon maintenance 作为连贯实验。

### 实验问题

- **Q4.1:** 取一个已知结果（如 prefix caching 提升 TTFT X%），该收益是否能在五阶段扰动协议下存活？
- **Q4.2:** 缓存失效事件后系统多快重新稳定？测量稳态吞吐的恢复时间。
- **Q4.3:** 持续负载漂移下（30 分钟内从短 prompt 渐变到长 prompt），摊销 goodput 相比一次性最优退化多少？

---

## 5. 策略层叠冲突

**核心判断：** 叠加争用缓解 + 迁移启发式 + 质量保障而不显式定义优先级会导致振荡。策略栈在倾斜或故障下可能互相打架。

### 实验问题

- **Q5.1:** 同时启用批处理优化 + prefix caching + continuous batching 准入控制。在什么负载条件下它们冲突？
- **Q5.2:** 两个独立策略（如抢占 + 动态批处理）无协调运行时，能否观察到可测量的振荡（延迟方差增加）？
- **Q5.3:** 添加简单优先级排序（硬约束 → 软目标 → 打破平局）是否降低同负载下的尾延迟方差？

---

## 6. 异构硬件上的状态中心调度

**核心判断：** 调度应在状态对象生命周期而非孤立请求上建模。未解决的需求是：调度器能联合推理谁触碰状态、状态应在哪里、移动代价多大、是否有并发变异。

### 实验问题

- **Q6.1:** 异构 NPU/GPU 环境下，状态感知放置（KV 在快内存，adapter 权重在慢层）在内存压力下是否优于均匀放置？
- **Q6.2:** 跨设备 KV 迁移 vs 重计算的代价对比？在什么序列长度下迁移更划算？
- **Q6.3:** 混合负载下（部分请求需要长 KV 上下文，部分是短请求），状态局部性感知路由 vs 轮询的 p99 延迟对比？

---

## 7. 分页 KV 管理中的写放大

**核心判断：** 分页、分离、传输压缩和恢复调度可改善 TTFT 或 goodput，但产生写路径或移动债务。一个机制如果将成本外化为延迟压缩，就不是高效的。

### 实验问题

- **Q7.1:** 持续 prefix caching 负载下，有用 KV 计算 vs 总 KV 数据移动（写入/读出 swap、worker 间传输）的比例如何随序列长度缩放？
- **Q7.2:** KV 压缩（量化 KV cache）是否按比例减少写放大，还是解压开销转移了瓶颈？
- **Q7.3:** "投机性" KV 保留（在慢存储中保留被驱逐的 KV 以备复用）在什么条件下比重新计算更划算？

---

## 8. 闭环 vs 开环准入控制

**核心判断：** 开环策略应被理解为局部近似。采样规则、压缩级别或驱逐启发式在一个扰动区间内工作良好，一旦另一个控制器改变负载形态就可能失效。

### 实验问题

- **Q8.1:** 静态准入阈值 vs 反馈驱动准入（基于队列深度+内存压力调整）。在什么突发强度下反馈回路变得必要？
- **Q8.2:** 静态策略遇到区间切换（短 prompt 突变到长 prompt）时，在人工重调前延迟过冲多少？
- **Q8.3:** 简单闭环启发式（"当 p99 超过 2x 目标 >5s 时降低准入率"）能否匹配更复杂的学到的控制器？
