# 第5讲：多维视角看论文写作

写作不只是叙述结果，而是把问题、机制和证据组织成可理解、可检查、可复现的研究论证。本页整理课程中的七种视角，不把课堂示例中的假设数字当成实际成果。

| 视角 | 阅读时会问什么 | 修订动作 |
| --- | --- | --- |
| 读者 | 解决什么问题，为什么值得继续读？ | 标题说明任务与边界；摘要交代问题、方法、结果；每段一个中心意思。 |
| 同行 | 与已有工作有什么可核查的差异？ | 用相同维度比较假设、机制和实验，提供复现条件，不靠贬低他人定位贡献。 |
| 审稿人 | 哪个假设或逻辑环节最容易被推翻？ | 写清前提、适用条件和局限，为关键主张准备证据。 |
| 实验研究者 | 改进是否来自声称的机制？ | 固定版本、负载和资源，控制混杂因素，设计消融与重复实验。 |
| 后续研究者 | 哪些结论可复用，哪些问题仍开放？ | 区分已验证结论、未验证假设与可扩展方向。 |
| 编辑 | 本文的核心贡献能否被准确概括？ | 突出一个清楚的贡献链；数字带条件和基线，不以醒目命名替代证据。 |
| 作者自己 | 如果不是作者，我会相信吗？ | 删除空泛的优越性表述，检查每个数字和引用，主动披露失败条件。 |

## 练习：同一段摘要改三遍

1. 圈出问题、核心机制、主要证据和边界；缺失处先补内容，不先润色。
2. 以同行视角补充最接近方法的差异，以审稿人视角检查结论是否超出实验。
3. 让未参与项目的人复述贡献。若其只能复述系统名字或实现流程，继续重写。

交付一页修改记录：原句、问题、改句、对应证据。涉及性能时使用实际记录；课堂占位数字不得进入论文。
